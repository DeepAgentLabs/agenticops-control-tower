# Control Tower

Which agents exist, what evidence do they have, and what needs attention?

<span id="what-it-does-today"></span>

## What it does

Fleet inventory, evidence posture, alerts, incident views, and approved operational workflows.

## What you need

Registrations, heartbeats, explicit evidence links, and operator configuration.

## Start here

Read a sample fleet offline; then start the local console.

[Follow the quickstart](developer-guide.md#quickstart).

## Scope

Fleet status does not turn a failed eval into a pass. Evidence ingestion and producer integrations must be configured explicitly.

[Read the detailed developer guide](developer-guide.md).
