# Security Policy

This project is pre-implementation software and should not yet be treated as a
production-ready control plane.

Until the first real write-capable release exists:

- do not assume any authentication or authorization surface is complete
- do not expose experimental services from this repo to untrusted networks
- do not treat scaffold APIs or examples as operationally hardened

If you discover a security issue in this repository, please report it
privately to the maintainers rather than opening a public issue.
