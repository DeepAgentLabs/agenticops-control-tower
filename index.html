Why it exists

More agents, less visibility.

Teams start with one agent and soon run dozens, across different frameworks, machines and owners. Without one shared list, nobody can answer simple questions quickly.

“Which agents do we even have?”

Agents live in different repos, notebooks and services. There is no single inventory.

“Is anything broken right now?”

A failed run or an agent that stops checking in is often noticed only when a user complains.

“Who approved that change?”

Configuration changes and fixes happen out of band, with no preview, no second person and no record.

Control Tower answers all three from one server: a fleet inventory, live alerts from the evidence your tools already produce, and approval-gated actions with an audit trail.

Ecosystem evidence posture

Push native Lens runs, Evals reports, Sidecar decisions and Chaos reports. Tower shows each as fresh, stale or missing per deployment and never recomputes their verdicts.

Live alerts and incidents

Every 30 seconds Tower turns failed Lens runs, overdue heartbeats and stale or missing evidence into deduplicated alerts, with an incident view and timeline.

Experimental · 0.4–0.7

Approval-gated changes

Preview a configuration change for one agent or a filtered fleet, have a second person approve it with a separate token, then execute it with per-target results and an audit trail.

Where it runs

Your laptop, or your server.

Control Tower is one Python service: the API, the CLI's server mode and the console run together. You host it; nothing is sent to DeepAgentLabs.

On your machine

Available in 0.8.0

Try it locally

Start the server on your laptop and open the console at http://localhost:8000/console/. Read a sample fleet offline first, with no server at all.

Access
Reader, writer and approval tokens you generate. No sign-up.
Where data lives
In memory, or a SQLite file with --database.
Install
From the repository: pip install ".[api]"

Best for: trying Control Tower, and single developers.

On your own server

Available in 0.8.0

Shared deployment tokens. Per-user accounts are planned.

How it works

Up and running in four steps.

0.8.0 is available on PyPI. The repository includes the sample files used below. Steps 3 and 4 need the api extra, which the install below includes.

  1. 1

    Install

    Clone the repository and install it with the api extra for the server and console.

    git clone https://github.com/DeepAgentLabs/agenticops-control-tower.git && cd agenticops-control-tower && pip install ".[api]"
  2. 2

    Read a sample fleet

    Answer read commands from the bundled snapshot, with no server or token.

    agenticops-control-tower --snapshot examples/sample_fleet_snapshot.json status
  3. 3

    Start the server

    Generate tokens once, then serve the API and console with a SQLite file so data survives restarts.

    agenticops-control-tower serve --database registry.sqlite
  4. 4

    Open the console

    Paste your reader token and select Connect / refresh. Register agents from the CLI or API.

    http://localhost:8000/console/

FAQ

Common questions.

Quick answers about cost, data, installing and what works today.

Still have questions? Ask the community on Discord, or open an issue on GitHub. Feature ideas are welcome too.
Ask on Discord Open an issue ↗
Is Control Tower free?

Yes. It's open source under the MIT license, like every DeepAgentLabs package.

Does my data leave my machine?

No. Control Tower runs on your own machine or server, and agents and tools push data to it. It doesn't call DeepAgentLabs or fetch anything from your producers.

How do I install the documented version?

Install the published version with pip install "agenticops-control-tower[api]==0.8.0", and clone the repository for example files: see getting started.

Does it fix agents on its own?

No. Detection only raises alerts and opens incidents. Every change and recovery needs a preview and a human approval, and recovery today covers one staging runtime. Reusable runbooks are planned for 0.9.

Is there an AI model inside?

No model is bundled. To investigate an incident with AI, connect a local Agentic MCP server to your own MCP host; Tower supplies the evidence.

Where do I ask questions or report bugs?

Open an issue on GitHub, or ask on Discord.
